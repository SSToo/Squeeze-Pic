# Rust 压缩优化验证（0.2.1）

日期：2026-10-14。环境：macOS Apple silicon，Rust 1.92.0，release 构建。

本次保持现有画质、尺寸和元数据设置，优化 Rust 核心的存储结构、像素处理和候选选择。

## 已实现

- PNG 开启可逆的调色板、颜色类型和位深简化；完全不透明的 alpha 可移除，灰度可用更紧凑的表示。禁用修改透明像素隐藏 RGB 的优化；原尺寸同格式 PNG 优化及严格无损路径在提交前逐像素及 ICC 校验。
- 带 ICC 或特殊色彩配置的原图不做 RGB 到灰度类型简化，避免颜色类型与配置文件不兼容；RGB ICC 仍可随 RGB/索引色输出保留。
- 混合及缩放使用 256 项 sRGB 线性值查表。不透明像素直接复制 RGB，全透明像素直接使用选定背景；半透明像素保持原线性光混合公式。
- 重编码候选逐个与当前最小结果比较。WebP 深度搜索从同时保留 3 份完整编码改为只保留当前最小结果和新候选；JPEG / PNG 共用这一筛选方式。WebP 的内容分类和 alpha 判断移出多轮循环。

## 同一组样本对照

Rust 示例生成 768 × 512 的合成样本。执行顺序为优化前、优化后、优化后、优化前；每次每项运行 3 遍，共 6 次，以下耗时取中位数，包含读取、处理、完整结果解码校验及写入，不含构建和程序启动。

体积百分比指“优化后相对于旧版已经压缩的输出”，不是相对于原图。

| 样本 / 操作 | 旧版输出 B | 优化后 B | 体积减少 | 旧版 ms | 优化后 ms |
| --- | ---: | ---: | ---: | ---: | ---: |
| 少色块图 | 3,733 | 1,354 | 63.7% | 401.91 | 203.28 |
| 16 级灰度 | 3,771 | 1,436 | 61.9% | 387.08 | 211.06 |
| 全彩渐变与噪声 | 274,394 | 260,533 | 5.1% | 1496.45 | 966.12 |
| 少色透明图 | 5,120 | 2,163 | 57.8% | 549.78 | 233.23 |
| 附 RGB ICC 的灰度图 | 4,121 | 1,846 | 55.2% | 438.04 | 196.46 |
| 全彩图转 JPEG | 20,115 | 20,115 | 0.0% | 69.99 | 46.00 |
| 透明图转 JPEG | 108,428 | 108,428 | 0.0% | 118.88 | 89.50 |
| 缩放后转 JPEG | 3,338 | 3,338 | 0.0% | 44.83 | 28.36 |
| WebP 严格无损 / 深度 | 1,764 | 1,764 | 0.0% | 41.35 | 33.03 |

5 类 PNG 样本比旧版输出再小 5.1%–63.7%，像素完全一致。3 项 JPEG 操作输出文件 SHA-256 与旧版相同，耗时中位数下降 24.7%–36.8%；WebP 对照也保持相同文件校验值。

这些是小规模合成样本，不能作为真实照片、所有图片或其他电脑的平均收益。耗时受系统负载和缓存影响；候选缓冲优化尚未单独测量进程峰值 RSS，不将它表述为已测得的整体内存降幅。

## 回归及安装包检查

- 工作区 24 项测试通过；新增调色板隐藏 RGB、低位深灰度、RGB ICC 类型兼容和 sRGB 混合参考公式回归。灰度简化覆盖快速、智能、深度三种策略。
- `cargo fmt --all -- --check`、工作区全部 targets 的 Clippy（拒绝 warning）、TypeScript 和前端构建通过。
- 从最终 `.app` 调用随包 Rust worker，确认版本 0.2.1，少色样本输出 1,354 B，与优化快照一致。应用签名和 DMG 完整性验证通过。

## 复测

```sh
cargo run -p squeeze-pic-core --release --example compression_bench -- current
```

默认使用 `tmp/compression-benchmark/` 的同一批样本。优化前后的 release 快照保存在本机该目录的 `baseline-bench` / `optimized-bench`；原始 6 次计时、编码信息和文件校验值见 [JSON 记录](benchmarks/compression-0.2.1.json)。

实现位置：`crates/squeeze-pic-core/src/pipeline.rs`、`transform.rs`；可复测样例：`examples/compression_bench.rs`。

配置依据：[oxipng 官方 Options 文档](https://docs.rs/oxipng/latest/oxipng/struct.Options.html)；色彩类型兼容约束依据 [W3C PNG iCCP 规范](https://www.w3.org/TR/png-3/#11iCCP)。
